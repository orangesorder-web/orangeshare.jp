ORANGESHARE NOTE

OrangeShareノート

制作現場からの気づき、SEO・WordPress・セキュリティなど、ホームページを考える人に役立つ話をまとめます。

このページは構成・デザイン確認用です。以下の記事はサンプルであり、公開済みの記事ではありません。

WEB SECURITY — サンプル記事

WordPressを安全に使い続けるために、まず確認したいこと。

ホームページを公開したら、それで終わりではありません。WordPress本体・テーマ・プラグイン・PHPなど、時間の経過とともに見直したい部分が増えていきます。

例えば、更新できない古いシステムが残っていないか、バックアップから復元できる状態か、誰が管理権限を持っているか。こうした基本的な確認が、運用の出発点になります。

サイトごとに使われている仕組みが違うため、まず現状を把握して、必要な対策の優先順位を整理することが大切です。

WEB DESIGN — サンプル記事

リニューアルは、全部作り直すことから始めなくてもいい。

ホームページが古く感じるとき、見た目だけを変えればよいとは限りません。お客様が知りたい情報が探しやすいか、文章が今の事業を正しく伝えているか、問い合わせの導線は分かりやすいか。

改善するポイントを先に整理すると、部分的な調整で十分な場合もあります。リニューアルの目的を決めることが、最初の大切な作業です。

FROM OUR DESK — サンプル記事

古いサイトの調査は、見えないところから始まります。

長く運用されてきたホームページでは、表から見えるページだけでなく、管理画面やサーバーの設定、過去の更新方法なども大切な情報になります。

何が使われているのかを丁寧に確認することで、安全に変更できる範囲が見えてきます。制作の前にある、そんな調査の仕事も少しずつ紹介していきます。
